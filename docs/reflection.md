# Reflection

**Original state.** The starting point (tag `original`, commit `eeeb047`) was my STATS 507 final project: one Jupyter notebook that fine-tuned BERT, DistilBERT and RoBERTa on SST-2. Packages were installed inside a cell with unpinned `!pip install`; the data and model revisions were not pinned; the three training cells were copy-pasted; results lived only in an in-memory dict; and plots were written to the project root. The saved notebook was broken: every training cell ended in a progress-bar `RuntimeError`, the summary CSV was empty and some figures were blank. The report had been assembled outside the project, so several of its numbers could not be traced to any data. About 10 GB of checkpoints made the project impossible to share as it was.

**Biggest challenges.** (1) The models cannot be shared or cheaply retrained, so I had to find the smallest checkpoint that still regenerates every result: each model's training log plus its validation logits (~200 KB). This split the pipeline into `make reproduce` (from committed artifacts, no PyTorch) and `make rebuild` (from raw data). (2) Reconciling the original report with the surviving checkpoints: only 18 of its 28 numbers reproduce, because BERT's first run was overwritten, the confusion matrix came from a partly reloaded model, and the training times include hours of laptop sleep (documented in `docs/discrepancies.md`). (3) Pinning an environment that installs on Python 3.11–3.14 across platforms.

**Most impactful improvements.** Committing small exported artifacts instead of models; pinning the data revision with a SHA-256 check; a single `make reproduce` that finishes in under a minute; and a CI workflow that runs the quick start from a fresh clone on Ubuntu and macOS. Tests that check the predictions reproduce the accuracy logged during training tie the artifacts back to the original run.

**What I would do differently.** Write scripts instead of a notebook from the start, pin versions and seeds (including the classification head) before training, save predictions and logs as files rather than in memory, and generate report numbers directly from code.

**Time spent** (approximate, from the commit timestamps; about 3 hours of transformation in total): restructuring, `.gitignore` and environment pinning, about 30 minutes; data download, metric functions and artifact export, about 20 minutes; tables, figures, generated report, training script and Makefile, about 10 minutes; tests, about 5 minutes; README and documentation, about 5 minutes; review, debugging and fixes (determinism tests, CI, corrected numbers and messages), about 2 hours.
